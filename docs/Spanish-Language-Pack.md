# Spanish language pack (`es_ES`)

The Tabletop Spanish tester-review pack targets **Spanish (Spain)** using the WordPress locale `es_ES`.

Tabletop honours the Companion-owned `gmrc_interface_locale` preference, so a player who selects **Español** in Companion receives the Spanish Tabletop interface without changing the shared campaign or another participant's language.

Files:

- `languages/great-marketrealm-tabletop-es_ES.po` — editable Spanish catalogue.
- `languages/great-marketrealm-tabletop-es_ES.mo` — compiled catalogue loaded by WordPress.

Canonical MarketRealm names and user-authored campaign content remain separate from interface localisation.
