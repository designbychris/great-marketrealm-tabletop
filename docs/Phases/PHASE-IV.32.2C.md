# Phase IV.32.2C — The Keeper Rearranges the Furniture

This presentation-only pass finishes the structural work needed before the live-play pixel treatment.

## Keeper Drawer Rail

Atlas and Bestiary remain independent drawers, but their tabs now behave as one Keeper rail. Opening either wide workspace moves the inactive sibling tab to the same outer edge while keeping its panel hidden. Switching drawers therefore feels like changing tools on one workbench rather than opening unrelated side panels.

## Table Command Header

The masthead now carries the current Scene, mode and grid registration alongside Table identity and viewer role. Exploration/Battle strips are compacted and the duplicate board Scene heading remains in the DOM for accessible labelling while its visible space becomes a slim action dock. The command region follows the same 1650px rhythm as battlefield plus Gathering.

## Gathering Seats

The old repeated PLAYER badge becomes a seat indicator. Dungeon Masters retain `DM`; players without a selected Companion character show `P`; players with a selected character show that character's token portrait with an accessible `Playing: …` label. Management controls and vitality are given distinct visual bands so Remove from Table no longer crowds identity.

No Scene, encounter, Fog, Vision, token, membership or persistence authority changes in this phase.
