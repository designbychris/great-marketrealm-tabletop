# Phase IV.34.7 — The Next Gathering

The Table now welcomes a campaign back between play nights without treating a new Session as a new campaign. After at least one completed Session, the Keeper sees **The Next Gathering**, the next authoritative Session number, and the existing Call Session lifecycle. Starting it creates only the new Session recording boundary: Scene, tokens, Fog, doors, lights, Atlas state, Companion campaign linkage and every other persistent Table state remain untouched.

The latest completed **Previously, in the MarketRealm…** recap remains available while the next Session is active, clearly labelled as the **Previous Session**, so historical context survives without contaminating the new Session identity. New deeds continue to bind to the newly active immutable Session ID through the existing Session-aware Chronicle repositories.
