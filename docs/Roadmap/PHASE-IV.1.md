# Phase IV.1 — The Empty Table

## Purpose

Create the smallest stable independent plugin foundation on which the Great Marketrealm VTT can safely grow.

## Certification Targets

- Stable plugin identity and namespace.
- Self-contained source autoloading.
- Idempotent application boot.
- Activation seeds schema/capacity foundations.
- Deactivation does not destroy game data.
- Companion availability uses a dedicated boundary.
- PHPUnit exists before gameplay systems arrive.

## Non-Goals

No tables, maps, tokens, initiative, encounters, fog of war, real-time networking, player joining, or capacity enforcement yet.
