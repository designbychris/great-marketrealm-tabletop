# Phase IV.28D — The Threshold Markers

The Keeper may mark intentional points of arrival on any Scene currently before them, including a Scene being prepared Behind the Curtain.

## Canonical rules

- Threshold Markers are Dungeon Master information and are never projected to Players.
- **Party Arrival** markers are authoritative entry points for selected Companion Characters entering a Scene for the first time.
- A character token already present in the destination Scene is never moved by a Threshold Marker. Its remembered Scene position wins.
- If several Party Arrival markers exist, arriving characters are distributed between them and then gently spread by grid-sized offsets to reduce stacking.
- If a Scene has no Party Arrival marker, Passage Between Places continues normally and no missing character tokens are automatically forged.
- **Monster Deployment** markers are persisted now as the placement boundary for Phase IV.29 — The Keeper's Bestiary. IV.28D does not automatically create monsters.
- Markers may be placed or removed only by an active Dungeon Master and only on a Scene belonging to that Table.
- Removing a Scene through **The Keeper Clears the Shelves** removes its Threshold Markers with the rest of its Scene-owned state.

## Living Table boundary

Opening a Scene remains the authoritative Passage Between Places action. Once the Scene is activated, the server checks its Party Arrival markers and forges only missing active-player Companion character tokens. Existing destination tokens are left untouched. The normal Living Table heartbeat then carries connected browsers into the destination with the resulting authoritative token state.
