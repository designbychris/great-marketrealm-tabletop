# Phase IV.32.5 — Pippin Discovers Pixel Art

The Scene Forge now speaks the same 16-bit visual language as the Tabletop shell and battlefield while retaining the exact deterministic world plan underneath it.

## Presentation contract

- Dungeon cells gain crisp stepped tile highlight/shadow marks without changing floor membership.
- Forest and village trees are projected as deterministic block canopies with pixel trunks and roots.
- Rock clusters become faceted pixel polygons rather than smooth curves.
- Village buildings keep their existing footprints while gaining square geometry, roof striping, crisp doors/windows/chimneys and hard shadows.
- Logs, wells, gardens and trails receive matching pixel-object vocabulary.
- Forge artwork uses crisp SVG rendering and square joins/caps.

## Authority boundary

This phase does not alter Scene Forge topology generation, floor arrays, obstacle placement, LOS barriers, doors, Keeper lights, grid registration, Fog state or encounter behaviour. Theme remains presentation-only and generated plans remain deterministic.
