# Phase IV.35.9B — Pippin Does Not Trust the Furniture

This closes the Mimic furniture loop without changing the already-certified
**Convert Now** behaviour.

The Keeper now has two deliberate choices for any `mimic_capable` Scene Object:

1. **Convert Now** — immediately replace the furnishing with the selected real
   Bestiary Mimic, as certified in IV.35.9A.
2. **Arm Disguise** — keep the furnishing visually and tactically unchanged,
   but persist a secret Bestiary Mimic identity on the Scene Object.

An armed disguise is visible as secret metadata only to the Dungeon Master.
Players continue to receive the ordinary innocent furnishing.

The Keeper may then **Reveal Mimic**, which deploys the stored canonical
Bestiary creature at the furnishing's exact coordinates and removes the Scene
Object only after successful deployment. **Disarm Mimic** removes the hidden
identity while leaving the furniture untouched.

This phase intentionally keeps revelation Keeper-controlled. Automatic
proximity/interaction traps can be added later without changing the
Scene Object → Bestiary conversion boundary.

> Pippin: “I am no longer categorising furniture as safe.”
