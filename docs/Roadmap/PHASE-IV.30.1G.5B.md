# Phase IV.30.1G.5B — Structural Evidence Corroboration

## The Grid Is Not the Dungeon

Hybrid Judgement must not promote the imported battlemap's printed/calibrated grid into LOS walls merely because those lines are straight, persistent, and grid-aligned.

This phase makes grid alignment supporting evidence only. A Structural candidate must now be corroborated by either nearby Living Contour geometry or asymmetric wall-body artwork beside the candidate. Repeated parallel/grid-aligned candidates without artwork corroboration are suppressed rather than allowed to resurrect geometry that Semantic Boundary Classification already rejected.

The phase deliberately preserves conservative uncertainty: it strengthens arbitration between readers without weakening Living Contour's semantic suppression, threshold protection, or partial-contour recovery.
