# Phase IV.21B — The Cartographer's Lens

The Cartographer's Lens changes the viewer's camera, not the battlefield.

The chamber can zoom from 25% to 300%, fit the complete map into the viewport, reset to 100%, and pan by dragging while zoomed. Battlemat artwork, calibrated rules grid and tokens transform together as one coordinate-space, preserving alignment.

Lens state is presentation-only. It does not save token coordinates, alter movement, rewrite grid calibration, or create a server mutation route. This keeps future fog and vision grounded in the certified battlefield coordinate-space rather than the viewer's camera.
